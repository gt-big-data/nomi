# apps/dashboard

Static internal dashboard published to GitHub Pages, regenerated from pipeline outputs.

- **Coverage** (NOMI-042): barcode resolution by store, brand vs store brand and category; products by
  category and scope; label section coverage.
- **Signal explorer** (NOMI-071): FAERS signals by ingredient, risk dimension and age band, with
  intervals and stated limitations.

Used by the team to track pipeline health and in the demo's data story.
